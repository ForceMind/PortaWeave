# M1-E：范围读取租约与原生生命周期

基于 `e86b1266e83864e68a736d52429a940070c6d615`；格式及既有 ABI 布局不变。

`Volume::acquire_range_view(handle, offset, length)` 只复制指定字节区间覆盖的块映射。文件总索引超过预算时，仍可获取小范围稳定读取租约。租约保存获取时的 EOF；覆盖、截断、取消链接、关闭源句柄及自动回收后仍读取旧版本。读取使用绝对文件偏移，整个请求必须位于申请区间内，越界明确返回 `InvalidRange`，不会把遗漏映射误读成零。空区间及 EOF 之外区间不分配块索引；空洞返回零，原 EOF 之后返回空内容。

范围租约和全文件租约共用既有 owner 级活动数与索引条目预算；COUNT 预检和索引加载均有 SQL 范围条件。偏移加法使用 checked arithmetic，并限制到有符号 64 位文件地址空间。准入拒绝不锁定写保护、不驱逐旧租约。

既有 C ABI 新增 `pw_read_view_begin/read/close`。token 仍为进程内唯一、绑定所属 volume；源文件关闭不释放租约，尚有租约时关闭 volume 返回 BUSY。失败不修改输出；成功后仍须分别检查维护健康状态。适配器有责任释放租约，不得无限保留。真实 C caller 覆盖覆盖后旧内容、范围拒绝、源句柄关闭、volume BUSY 与重复关闭。

这不是 OS mmap、内核缓存一致性或完整文件系统同步的实现。索引预算不是精确堆字节预算；一个范围引用仍可能保留整个物理数据段。verify、GC 候选与恢复的全局资源预算需要继续完善。

测试覆盖跨块区间、累计预算、稀疏超大逻辑文件、零长度、旧 EOF、溢出、截断/删除/关闭/回收与重开校验。真实执行结果以本轮 PR 对应 SHA 的 CI 为准，不能把代码存在写成 PASS。真实 macOS/Windows 挂载、Codex 沙盒、exFAT 与物理断电仍为 NOT_RUN/BLOCKED。
